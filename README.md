# Khanh B. Trang: personal website

This repository serves the personal website of **Khanh B. Trang, MD, MPH, PhD**, published
with GitHub Pages at [baokhanhtrang.github.io/a2t](https://baokhanhtrang.github.io/a2t/).

It is a finished, static website, not research code. It holds only what a browser downloads
to display the site: the pages, stylesheets, minified scripts, fonts, images, figures and
narration audio. No analysis pipelines, study data or source code for the research live here,
and the repository is not meant to be cloned, built or reused.

| Path | What it is |
|---|---|
| `index.html` | the landing page: a zoom from a patient's concern to a druggable target, with a one-minute brief |
| `how.html` | how genetics and multiomics are joined: evidence streamline, evidence matrix, study-design notes |
| `stories/` | two published studies, each drawn on the same streamline, with their figures |
| `work.html` | papers by organ system and year |
| `about.html` | background and contact |
| `css/`, `js/`, `fonts/`, `img/`, `audio/` | styles, bundled scripts, typefaces, images and figures, narration |
| `.github/workflows/pages.yml` | publishes this folder to GitHub Pages on every push |

The illustrated scenes and the narration were generated for this site. The dot animations of
the body, tissues and cell types are synthetic illustrations and contain no study data. Figures
from published papers are reproduced with their source given in each caption.
